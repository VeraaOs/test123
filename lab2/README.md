# report-shell (лабораторная работа №2)

Переработанная версия `Test_FP1` под требования ЛР №1: ADT команд и ошибок,
`Either`/`Option`, разделение бизнес-логики и интерфейса.

Старый проект `Test_FP1` не изменялся.

## Запуск

```bash
sbt run
```

Требуется `config.json` в рабочем каталоге. Отчёты сохраняются в `reports/`.

## Архитектура

| Файл | Слой | Назначение |
|---|---|---|
| `Model.scala` | домен | данные сессии, шагов, команд, правил |
| `Errors.scala` | домен | `CommandError`, `SessionError`, `StorageError`, `ShellError`, `AppError` |
| `Commands.scala` | разбор | ADT `Command` и чистая `CommandParser.parse` |
| `SessionLogic.scala` | бизнес-логика | чистые операции над сессией, предупреждения, статус |
| `Report.scala` | бизнес-логика | чистая сборка Markdown |
| `Storage.scala` | хранение | чтение конфигурации и запись отчётов, `Either[StorageError, ?]` |
| `Shell.scala` | интеграция | запуск команд и проверка каталогов, `Either[ShellError, ?]` |
| `Ui.scala` | интерфейс | `Ui`, `MenuOption[A]`, консольная реализация |
| `View.scala` | интерфейс | текст справки и статуса |
| `Messages.scala` | интерфейс | преобразование ошибок в текст |
| `Main.scala` | приложение | цикл программы, связывание слоёв |

## Соответствие требованиям

1. Пользовательский ввод разбирается один раз в `CommandParser`; дальше используется `Command`.
2. Ожидаемые ошибки — отдельные ADT (`CommandError`, `SessionError`, `StorageError`, `ShellError`, `AppError`).
3. Ошибки операций возвращаются через `Either`; исключения ловятся только на границах Java API.
4. Отсутствие значения — `Option` (`session`, `stepName`, аргументы команд).
5. Бизнес-логика (`SessionLogic`, `Report`) не печатает и не читает ввод.
6. Коллекции и контейнеры обрабатываются через `map`, `flatMap`, `fold`, `collect`.
7. Пользовательские сценарии исходной программы сохранены.

## Команды

```
starts "Название"   — начать сессию
ends                — завершить сессию и сохранить отчёт
prootd <путь>       — установить корневой каталог
mstep "Название"    — начать новый шаг
mnote "Текст"       — добавить заметку
mskip               — исключить следующую команду из отчёта
mstatus             — показать состояние сессии
mpreview            — создать предварительный отчёт
help                — справка
exit / quit         — выход
```

Любая другая строка выполняется как команда shell и записывается в текущую сессию.
